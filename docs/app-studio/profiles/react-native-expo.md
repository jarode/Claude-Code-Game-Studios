# React Native / Expo / Android / iOS
**Identify:** Expo SDK, app config, navigation, state/persistence, notification permissions, deep links, Android/iOS build tooling and device matrix.
**Core checks:** app startup, safe-area and font scaling, back navigation, denied permission, offline/resume, TTS and accessibility, secure token storage.
**Safe commands:** validate existing package scripts, run unit tests and local emulator/device builds when available; never equate metro output with a valid release binary.
**Acceptance:** real device or emulator run plus navigation/data flows, visual and accessibility tests, and reproducible build artifact.
**Release risks:** store signing credentials, environment leaks, background-notification changes and incompatible storage migrations.
